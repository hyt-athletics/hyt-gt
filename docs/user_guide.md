# 用户使用手册

> 本手册面向使用本软件进行数据处理的用户，不需要编程经验。

---

## 1. 安装与启动

### 1.1 需要什么

- Windows 11 电脑（也支持 macOS 和 Linux）
- Python 3.11 或更高版本（从 [python.org](https://www.python.org/downloads/) 下载）

> 安装 Python 时，请勾选「Add Python to PATH」选项。

### 1.2 安装步骤

打开命令提示符（按 Win+R，输入 `cmd`，回车），逐行输入以下命令：

```
cd 你的项目路径\geophys-tool
pip install uv
uv sync
```

如需三维可视化功能（查看三维模型），额外运行：

```
uv sync --extra 3d
```

### 1.3 启动软件

```
python main.py
```

软件窗口会打开，标题栏显示工作区路径。

## 2. 认识界面

软件界面分为四个区域：

| 区域         | 位置 | 功能                                                  |
| ------------ | ---- | ----------------------------------------------------- |
| **项目树**   | 左侧 | 显示所有钻孔和数据文件，双击文件可预览                |
| **结果显示** | 中央 | 显示处理结果的曲线图或三维模型（有两个标签页：2D/3D） |
| **算法面板** | 右侧 | 选择算法、设置参数、运行算法                          |
| **执行日志** | 底部 | 显示运行状态、错误信息、输出文件路径                  |

工具栏按钮（从左到右）：

| 按钮       | 功能                    |
| ---------- | ----------------------- |
| + 新建钻孔 | 创建新的钻孔项目        |
| 导入数据   | 导入 LAS/CSV 等数据文件 |
| 运行算法   | 运行当前选中的算法      |
| 运行流水线 | 运行多步骤自动处理      |
| 刷新       | 刷新项目树              |

## 3. 第一次使用：完整操作流程

### 第一步：新建钻孔

1. 点击工具栏「**+ 新建钻孔**」
2. 输入钻孔名称，例如 `BH-001`
3. 点击确定
4. 左侧项目树出现新钻孔

### 第二步：导入数据

1. 点击工具栏「**导入数据**」（或按 Ctrl+O）
2. 选择你的数据文件：
   - `.las` 文件 → 测井数据（自然伽马、电阻率等）
   - `.csv` 文件 → 任何数值数据
   - `.segy` 文件 → 地震数据
3. 系统会问你：这个数据属于哪种方法？
   - 选择 `logging`（测井）/ `tem`（瞬变电磁）/ `ert`（电阻率）等
4. 点击确定，数据自动导入
5. 左侧项目树中出现导入的文件

### 第三步：运行算法

1. 在右侧算法面板的**钻孔下拉框**中选择你的钻孔
2. 展开算法树，找到你想运行的算法，**单击选中**
3. 下方出现参数设置区域：
   - 灰色文字（如 `← raw/GR.csv`）表示自动从数据文件读取，不需要手动设置
   - 数字输入框可以调整参数，也可以用默认值
4. 点击「**运行算法**」按钮
5. 状态栏显示运行进度，完成后结果自动显示在中央区域

### 第四步：查看结果

- **曲线图**：算法输出的一维/二维数据会自动绘制在 2D 标签页
- **三维模型**：如果输出包含三维数据或网格文件，会在 3D 标签页显示
- **输出文件**：在左侧项目树的 `processed/算法名/` 下可以看到所有输出文件
- **双击文件**可以重新加载查看

## 4. 运行流水线（多步骤自动处理）

流水线可以把多个算法串起来，前一步的输出自动传给下一步。

1. 在右侧面板选择流水线
2. 选择钻孔
3. 点击工具栏「**运行流水线**」

### 内置流水线

| 流水线名称         | 包含步骤                       | 用途                 |
| ------------------ | ------------------------------ | -------------------- |
| 测井三算法滤波对比 | SG滤波 → 小波去噪 → Kalman平滑 | 对比三种滤波效果     |
| TEM 一维工作流     | empymod正演 → Occam反演        | TEM 数据正反演全流程 |

## 5. 数据存放位置

所有数据存放在你的用户目录下的 `geophys-workspace` 文件夹中：

```
C:\Users\你的用户名\geophys-workspace\
└── boreholes\
    └── BH-001\                   ← 你的钻孔
        ├── logging\
        │   ├── raw\              ← 导入的原始数据（CSV格式）
        │   │   ├── GR.csv
        │   │   └── COND.csv
        │   └── processed\        ← 算法输出结果
        │       └── log_preproc_savgol\
        │           ├── curve_filtered.csv    ← 滤波后曲线
        │           ├── snr_improvement.txt   ← 信噪比改善值
        │           └── run_meta.json         ← 运行记录
        ├── tem\
        │   ├── raw\
        │   └── processed\
        └── ert\
            ├── raw\
            └── processed\
```

**如何用 Excel 打开结果：**

- 找到 `processed/算法名/` 下的 `.csv` 文件
- 双击用 Excel 打开即可查看数据

## 6. 支持的数据格式

### 导入格式

| 格式         | 扩展名                 | 说明                           |
| ------------ | ---------------------- | ------------------------------ |
| LAS 测井     | `.las`                 | 标准测井数据格式，包含多条曲线 |
| SEG-Y 地震   | `.segy`, `.sgy`        | 地震反射/折射数据              |
| CSV 文本     | `.csv`, `.txt`, `.dat` | 逗号/制表符分隔的数值数据      |
| VTK 网格     | `.vtk`, `.vtu`, `.vts` | 三维网格模型（需安装 3D 依赖） |
| 自定义二进制 | `.bin`                 | 自定义格式的二进制数据         |

### 输出格式

| 类型          | 格式            | 说明                             |
| ------------- | --------------- | -------------------------------- |
| 一维/二维数组 | `.csv`          | 可用 Excel 直接打开              |
| 三维数组      | `.npz`          | NumPy 压缩格式，可用 Python 读取 |
| 标量值        | `.txt`          | 纯文本，一个数值                 |
| 网格模型      | `.vtk`/`.vtu`   | 可用 ParaView 打开               |
| 运行记录      | `run_meta.json` | 包含时间戳、参数、警告信息       |

## 7. 常见问题

### 运行时提示「输入文件缺失」

**原因**：算法需要的数据文件不在钻孔的 `raw/` 目录中，或者**文件名不匹配**。

这是新用户最常遇到的问题。比如：

- 你导入了 LAS 文件，里面伽马曲线叫 `GAMN`，但算法期望的是 `GR.csv`
- 系统会提示类似：`输入文件不存在: .../raw/GR.csv`

**解决**：

1. 先通过「导入数据」导入你的数据
2. 打开 `raw/` 文件夹，查看实际生成的文件名
3. **如果文件名不一致**，有两种方法：
   - 方法 A：**手动复制文件并重命名**。例如把 `GAMN.csv` 复制一份为 `GR.csv`
   - 方法 B：修改算法的 `manifest.json`，把 `"file": "GR.csv"` 改为 `"file": "GAMN.csv"`

> 提示：软件运行前会检查输入文件是否存在，并列出缺失的文件名，方便你对照。

### 运行时提示「模块未找到」(ImportError)

**原因**：算法需要额外的 Python 库，但还没有安装。

**解决**：在命令提示符中运行 `pip install 库名`。

### 界面中文显示为方块

**原因**：系统缺少中文字体。

**解决**：

- Windows：一般不会出现此问题
- Linux：运行 `sudo apt-get install fonts-noto-cjk`
- macOS：系统自带中文字体，重启软件即可

### 算法运行时间很长

正常情况。三维反演可能需要几十秒到几分钟。状态栏会显示进度百分比，请耐心等待。

### 如何找到输出文件

运行完成后：

1. 查看底部「执行日志」，其中显示了输出文件路径
2. 或在左侧项目树中展开 `processed/` 目录
