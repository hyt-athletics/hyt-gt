# 多方法井中地球物理建模平台 — 当前状态与下一步计划

> 更新时间: 2026-03-30
> 当前版本: BHGPS v1.3
> Python 环境: 3.11.14 @ `geophys-tool/.venv`
> 已验证关键库: `SimPEG 0.25.2`, `discretize 0.12.0`, `harmonica 0.7.0`, `numba 0.64.0`

---

## 一、当前定位

项目当前已经明确为：

- 井中地质建模与多物性录入平台
- 井中重磁位场网格与约束工作流平台
- 外部正反演库统一适配平台
- 结果管理、可视化、VTK/ParaView 导出平台

不再把主线定义成“自研复杂求解器平台”。当前原则是：

- 正演算法优先使用积分核、解析核和公开外部库
- 反演算法优先使用高斯牛顿系、稀疏/紧致正则和可解释约束
- `PINN / CNN` 只作为未来可能的辅助模块，不作为当前井中重磁主求解链
- 有限差分/有限体积/有限元保留给后续电磁、波动类方法，不作为当前井中重磁主线

## 三、为什么主线不是“有限差分 + CNN/PINN”

当前项目主线是井中重磁，而不是通用地球物理求解器。

对井中重磁位场问题，更合理的路线是：

- 正演：体元积分 / 棱柱积分 / 解析核 / 公开位场库
- 反演：高斯牛顿系 + 可解释约束 + 稀疏/紧致正则

不优先走下面这条路：

- 正演主线切到有限差分
- 反演主线切到 `PINN / CNN`

原因很直接：

- 井中重磁的主流工作流本来就是位场体元积分与约束反演
- 当前平台最需要的是建模、网格、约束、解释、导出与交互
- `PINN / CNN` 更适合未来做初值预测、筛选、后处理，不适合作为当前商业化工作流主引擎

## 四、下一阶段目标

下一阶段目标不是增加更多求解器，而是把当前位场工作流继续做深，向成熟商业软件的公开工作流靠拢。

### 阶段 A：Petrophysical Prior 与 Constraint Voxel

目标：

- 把当前 `property reference` 扩展成更明确的先验与约束体系统

计划内容：

- 引入 `hard / soft constraints`
- 引入 `constraint voxel` 掩膜层
- 支持不同区域不同约束强度
- 在反演结果与切片中显示约束区域

预期文件：

- `inversion/gravity_simpeg.py`
- `inversion/magnetic_simpeg.py`
- `mesh/strategy.py`
- `export/vtk_export.py`
- `visualization/plot_gravity.py`
- `visualization/plot_magnetic.py`

### 阶段 B：剩磁工作流接入

目标：

- 先把剩磁参数接入解释层，而不是一步到位追求完整剩磁反演

计划内容：

- 在可视化中叠加 `remanent_mag / inclination / declination`
- 在磁法 survey 与结果摘要中明确区分：
  - 感应磁化
  - 剩磁参数
- 先支持“剩磁先验/解释层”，后评估“剩磁求解层”

### 阶段 C：Survey-Aware Mesh Template 与 QC 面板

目标：

- 把网格策略从自动生成升级成“可解释的模板库”

计划内容：

- 为井中重力、井中磁法分别预置 forward / inverse mesh template
- 输出模板名称、ROI 范围、目标单元尺寸、近井半径、异常体 padding
- 增强菜单和状态栏中的 `mesh_qc` 可读性

### 阶段 D：为后续多方法扩展预留接口

目标：

- 不立刻实现复杂电磁/声波求解器，但把平台接口继续做稳

计划内容：

- 保持 `adapters/` 的黑盒接入方式
- 为 `DC/IP/TEM/Acoustic CT` 预留统一 survey/model/result 结构
- 继续避免方法实现散落到 `workflow` 中

## 五、下一轮具体实施顺序

建议按下面顺序推进：

1. 在重力和磁法反演里加入 `constraint voxel` 与区域权重
2. 在 VTK 导出中增加约束层和权重层
3. 在切片图中增加先验/更新区/固定区叠加显示
4. 把剩磁参数接入磁法 survey、metadata 和可视化
5. 最后再评估是否值得把剩磁推进到真正求解层
